Graph Structural Properties

The system represents interactions as a bipartite undirected graph $G = (U \cup I, E)$ where edges connect users exclusively to items (no user-user or item-item edges exist directly in the interaction graph). NetworkX mathematically verifies that $G$ is strictly 2-colorable (bipartite). Recommendation scoring computes paths of length 3 ($u \to \text{item} \to v \to \text{candidate}$) or projected collaborative similarity.

Distributed Recommendation Engine Architecture

Master-Worker Process Topology with Process-Local Graph Indexing

1. Master-Worker Process Orchestration

To achieve high throughput and eliminate lock contention:

  • Master Process: Receives target user requests or user batches. Identifies candidate item subsets and partitions candidates/users into $P$ balanced chunks.
  • Worker Processes: Initialized once with read-only memory references to graph adjacency hash tables. Workers compute similarity metrics concurrently across their assigned partitions.
  • Result Aggregator: Master gathers candidate scores via non-blocking inter-process communication (IPC) queues, performs global sorting, and extracts Top-$K$ recommendations.

2. Common Neighbors (Bipartite 3-Hop Walk)

Measures the number of shared items between target user $u$ and other users $v$ who interacted with candidate item $c$:

Score_CN(u, c) = Σ_{v ∈ N(c) \ {u}} [ |N(u) ∩ N(v)| × weight(v, c) ]

Notice that this is mathematically identical to counting all 3-hop walks $u \to i \to v \to c$ connecting user $u$ to candidate item $c$ in the bipartite graph.

3. Jaccard Similarity (Normalized Overlap)

Normalizes neighborhood overlap by the total union of interacted items:

Jaccard(u, v) = |N(u) ∩ N(v)| / |N(u) ∪ N(v)|

Score_Jaccard(u, c) = Σ_{v ∈ N(c) \ {u}} [ Jaccard(u, v) × weight(v, c) ]

4. Parallel Performance Formulation & Amdahl's Law

We evaluate distributed speedup and efficiency using standard parallel computing formulations:

Speedup: S(P) = T_seq / T_par(P)
Parallel Efficiency: E(P) = S(P) / P × 100%
Amdahl's Law Limit: S_max = 1 / [ (1 - f) + (f / P) ]

Where $P$ is the worker process count, $T_1$ is the sequential baseline execution time, and $f$ is the parallelizable fraction of the workload.
